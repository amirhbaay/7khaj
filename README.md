# بازی چهار برگ ۱۱ (پاسور / هفت‌خاج) — نسخه چندفایلی قابل نصب (PWA) و آفلاین

این بسته شامل کدهای کامل، ماژولار و تست‌شده بازی **چهار برگ (پاسور ۱۱ / هفت‌خاج)** بر اساس سند جامع قوانین و استراتژی صندلی‌هاست.

## ساختار فایل‌های پروژه
- `index.html`: فایل اصلی رابط کاربری بازی (واکنش‌گرا برای موبایل و دسکتاپ، تم پیش‌فرض روشن + حالت تیره)
- `css/styles.css`: استایل‌های کامل میز پاسور، برگ‌ها، انیمیشن‌ها، تم روشن و تیره و مودال‌ها
- `js/lz.js`: موتور فشرده‌سازی و بازگشایی آفلاین **LZ-String** (`UTF-16` و `URI-Safe Base64`) برای ذخیره بسیار کم‌حجم وضعیت بازی و آمار در `localStorage`
- `js/engine.js`: موتور قوانین ۵۲ برگی چهار برگ ۱۱ (قانون تعویض سرباز در ۴ برگ اول زمین، الگوریتم زیرمجموعه جمع ۱۱، قوانین شاه/بی‌بی/سرباز، ۴ استثنای حیاتی سور، قانون آخرین بردارنده زمین و محاسبه ۲۰ امتیاز پایه + سور تا سقف ۶۲)
- `js/ai.js`: هوش مصنوعی موقعیت‌محور بر اساس صندلی‌های چهارگانه (نفر اول، دوم، سوم و چهارم/دیلر) و شمارش کارت‌ها
- `js/audio.js`: سینتی‌سایزر صوتی آفلاین مبتنی بر Web Audio API (بدون نیاز به فایل صوتی خارجی)
- `js/app.js`: کنترلر رابط کاربری، مدیریت نوبت‌ها، مودال «دست قبلی»، مودال انتخاب ترکیب برداشت و مدیریت کدهای پشتیبان LZ
- `manifest.json` و `sw.js`: فایل‌های نصب وب‌اپلیکیشن پیش‌رونده (PWA) و کش کامل آفلاین

## نحوه اجرا و نصب
1. **اجرای مستقیم آفلاین**: کافی است فایل‌های زیپ را استخراج (Extract) کرده و فایل `index.html` را در هر مرورگر موبایل یا کامپیوتر باز کنید.
2. **نصب به عنوان اپلیکیشن (PWA)**: در صورت باز کردن پوشه از طریق یک وب‌سرور محلی (مانند `npx serve .` یا `python3 -m http.server 8080`) یا هاست شخصی، دکمه **«📲 نصب بازی»** در نوار بالای صفحه فعال می‌شود و کل فایل‌ها توسط Service Worker (`sw.js`) در حافظه مرورگر کش می‌شوند.
